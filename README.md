# 원룸관리

원룸 임대관리 Android 앱 **원룸관리**의 소개·다운로드 페이지입니다.

- 페이지: https://projmaro.github.io/roomrental/

암호를 아는 사람만 볼 수 있는 페이지예요. 페이지 본문(`data/*.enc`)과 설치 파일(`download/*.apk.enc`)은
암호로 암호화돼 있어(AES-256-GCM, 키는 PBKDF2-SHA256으로 생성), 페이지에서 암호를 입력해야 풀립니다.
암호는 배포한 사람에게 문의하세요.
